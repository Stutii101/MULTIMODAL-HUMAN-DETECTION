# MULTIMODAL HUMAN DETECTION

AI-based multimodal human fatigue and alertness monitoring system.

## Overview

A real-time computer vision project for monitoring facial indicators associated with fatigue and alertness using MediaPipe Face Landmarker and OpenCV.

## Features

- Real-time face landmark detection
- Facial expression analysis
- Eye Aspect Ratio (EAR)-based fatigue detection
- Smile detection
- Real-time webcam monitoring

## Technologies

- Python
- OpenCV
- MediaPipe
- NumPy

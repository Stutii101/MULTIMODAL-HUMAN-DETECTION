System Architecture & Deployment Specifications

⚡ Real-Time Client Vision Engine

Runs Google MediaPipe Vision Tasks (FaceLandmarker) via WebAssembly and WebGL directly in the user's browser. This ensures zero network latency (30 FPS), complete privacy (camera frames never leave your computer), and direct hardware webcam integration.

🐍 Python Serverless Backend

The live Vercel serverless function at api/index.py handles telemetry ingestion, scoring formulas, and health checks over HTTPS. It provides standardized REST endpoints (/api/health and /api/analyze) with CORS support.

💻 Preserved Desktop OpenCV Script

The original desktop OpenCV application (faceyesmile.py) is completely preserved in the repository. Users who prefer a local terminal application with desktop GUI popups can run it via python faceyesmile.py with requirements-local.txt.
